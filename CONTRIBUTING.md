# Contributing to PvPHistory

Thanks for wanting to help. Here's how each kind of help reaches the addon.

## Reporting a problem

[Open an issue](https://github.com/xenulive/wow-pvp-history/issues/new/choose) and pick **Something
isn't working**. The form asks for your version, what happened, and the debug log, which is usually
enough to find the cause. [Troubleshooting](https://github.com/xenulive/wow-pvp-history/wiki/Troubleshooting)
covers the problems people hit most, so check it first.

## Questions and ideas

Ask a question or suggest a feature in
[Discussions](https://github.com/xenulive/wow-pvp-history/discussions). The
[guide](https://github.com/xenulive/wow-pvp-history/wiki) explains every window and setting, and
[Questions](https://github.com/xenulive/wow-pvp-history/wiki/Questions) has short answers to what people
ask most.

## Code changes

This repository holds each release as it ships. It's rebuilt from the development tree every time a
version comes out, so a pull request opened here can't be merged as it stands, and the next release
would replace it anyway.

If you've found a fix, open an issue that describes the problem and the change, and paste the code or
a diff into it. It gets made in the development tree and ships in the next release.

## Privacy

Issues and Discussions are public. The debug log holds no player names and is safe to paste. A history
export or a CSV holds the names of everyone you've played with, so don't post one here.
